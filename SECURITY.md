# Security Policy

Osun EduOS is designed to hold records about children, teachers and schools. We take security and privacy seriously, even at the prototype stage.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. Include:

- what the issue is and where it is (file, screen or URL);
- steps to reproduce it;
- the possible impact.

We aim to acknowledge reports within 3 working days and to agree a fix and disclosure timeline with you.

## Supported versions

| Version | Supported |
| --- | --- |
| `main` branch of each repository | Yes |

## Data protection

- The prototype uses fictional sample data only. If you find anything that looks like real personal data in any Osun EduOS repository, report it as a security issue.
- The production system will handle personal data under the Nigeria Data Protection Act 2023. See the [architecture document](https://github.com/Osun-eduos/osun-eduos/blob/main/docs/architecture.md) for the planned security controls.
